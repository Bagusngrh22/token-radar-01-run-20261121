The best token launch radar: read a sealed snapshot of every protocol
DefiLlama tracks, work out which ones still record no token and are not a
wrapped or staked product of one that trades, and rank them by what their
launch would be worth. A web dashboard shows the board, a detail view for
each protocol and the steps to farm it. Built by an AI agent for make.fun's
"Build the best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
